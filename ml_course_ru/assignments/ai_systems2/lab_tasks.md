# Задания на лабораторные работы по дисциплине "Системы искусственного интеллекта", 7 семестр

## 1 лабораторная работа
Необходимо разработать модель глубокого обучения с использованием библиотек Keras или PyTorch для решения задачи классификации изображений.
Датасет можно выбрать любой [отсюда](https://huggingface.co/papers/trending) или из других источников.
Датасет нужно загружать с диска. Необходимо разработать средства визуализации результатов (примеры классификации).

## 2 лабораторная работа
Используйте механизмы аугментации данных для задачи из первой лабораторной работы, чтобы повысить точность модели.

## 3 лабораторная работа
Разработайте модель генерации текстов по выбранному датасету. 

## 4 лабораторная работа
Разработайте модель сегментации изображений по выбранному датасету: https://paperswithcode.com/datasets?q=Image+Segmentation&v=lst&o=match

Задание может быть индивидуальным по согласованию с препоадвателем.
