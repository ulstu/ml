# Общее задание


Ниже предложены датасеты. Можно предложить свой датасет в рамках схожей тематики. Необходимо выбрать оценку, на которую вы претендуете, и выполнить необходимый объем лабораторных работ. 
По результатам сделать отчет.

На 3:

Лабораторная работа 1. Обобщенная постановка задачи

Лабораторная работа 2. Провести предобработку данных. Разбить на тестовую и обучающую выборки (не забыть про кросс-валидацию).

Лабораторная работа 3. Реализовать модель на обучающей выборке. Поэкспериментировать с разными параметрами. Сделать выводы.

Лабораторная работа 4. Протестировать модель на тестовой выборке, сделать вывод. Поэкспериментировать с разными параметрами. Сделать выводы.

На 4:

Лабораторная 5-6. Повторить лабораторные 3 и 4 на другой модели. Сравнить и сделать вывод.

На 5:

Лабораторная работа 7. Написать статью для конференции "ИМАП" на основе выполненных работ.






Задача №1. Распознавание схем. Описание: На вход сервиса поступает фотография, на которой указана схема помещения с указанием размеров в оговоренных единицах измерения. На выходе - 2-х мерная векторная модель помещения, которая построена с учетом указанных размеров.
Задача №2. Оптимальная расстановка мебели в помещении. Описание: на вход подается 2-х мерная модель помещения и набор типоразмеров, которые нужно расположить в этом помещении наиболее оптимальным образом. Параметры оптимальности мб разными: максимизация свободной площади, расстановка вдоль определенной стены и т.п.
Задача №3. Голосовой помощник. Описание: реализовать модель для распознавания определенного набора голосовых команд. На вход подается команда голосом, на выходе результат распознавания в виде текстового или мнемонического описания
